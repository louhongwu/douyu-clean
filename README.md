# 斗鱼纯净直播助手（douyu-clean）

> 白名单式去广告 · 深色护眼 · 真实数据 · 自动全屏 · 弹幕增强，一个脚本搞定斗鱼直播间。
>
> 当前版本：**v13.24**（2026-08-14）

一个基于 **Tampermonkey（油猴）** 的斗鱼直播间增强用户脚本。只保留「直播主画面 + 弹幕栏」，其余导航、榜单、活动、悬浮窗、推广一律视为广告隐藏；另带真实数据面板（活跃/弹幕/礼物/贵宾/粉丝）、自动网页全屏、拾取元素去广告等实用功能。

---

## ✨ 功能亮点

1. **白名单式去广告**：只保留「直播主画面 + 弹幕栏」，其余结构一律隐藏，广告清得干净、不留空容器，直播画面始终居中。
2. **🎯 拾取元素（可视化点选去广告）**：不会写 CSS？点「拾取元素」后直接点漏掉的广告，自动生成隐藏规则并立即生效（左键=加入规则，Shift+左键=选整个广告块，Esc 或右键=结束）。
3. **布局级自动兜底**（默认开）：不依赖斗鱼类名，自动回收把直播画面顶出视口的大块广告容器，斗鱼改版或上新活动也拉得回画面。
4. **视口锁定模式**（默认关·实验性）：播放器+弹幕栏钉死视口、页面不可滚动，从布局上彻底免疫新增广告。
5. **深色护眼背景**：夜间看播不刺眼。
6. **真实数据面板**：今日活跃 / 已播时长 / 弹幕人数 / 礼物价值 / 贵宾 / 粉丝，图标+数字一目了然，鼠标悬浮显示完整说明；主播换房/改标题也能自动识别真实房号（v13.24 起更稳）；每 5 分钟自动刷新 + 手动刷新按钮兜底。
7. **自动网页全屏**（可开关）：进房即享大屏，弹幕栏依然保留。
8. **可拖动齿轮按钮 + 面板自动收起**：⚙ 按钮可拖到任意位置，面板鼠标移开自动关闭、5 秒无操作自动收起。
9. **弹幕无限收藏 + 收藏搜索**：官方 50 条上限不再愁，超出自动转存本地。
10. **图片弹幕**：与 DouyuEx 标记互通。
11. **自动抢礼物红包**（默认关）：检测到礼物红包自动出手，无需粉丝牌门槛。
12. **半自动抢宝箱**（默认关·实验性）：到点自动领取。
13. **检查更新 + 更新说明**：⚙ 面板一键检查 GreasyFork 新版本。

## 📥 安装方法

### 第 1 步：安装 Tampermonkey（油猴）扩展

- **Microsoft Edge**：打开 [Edge 加载项商店 - Tampermonkey](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)，点「获取」→「添加扩展」。
- **Google Chrome**：打开 [Chrome 网上应用店 - Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)，点「添加至 Chrome」。

安装完成后，浏览器右上角会出现 Tampermonkey 的黑色图标（🕷️）。

### 第 2 步：安装本脚本（二选一）

**方式 A：打开脚本文件直接安装（推荐）**

1. 打开本仓库里的脚本文件：[douyu-clean-v13.24.user.js](./douyu-clean-v13.24.user.js)；
2. 点击文件页右上角的 **Raw** 按钮（或直接访问 [raw 安装链接](https://raw.githubusercontent.com/louhongwu/douyu-clean/main/douyu-clean-v13.24.user.js)）；
3. Tampermonkey 会自动弹出安装页面，点击绿色 **「安装」** 按钮即可。

**方式 B：拖入 Tampermonkey 管理面板**

1. 点击浏览器右上角 Tampermonkey 图标 → **管理面板（Dashboard）**；
2. 点上方标签 **「实用工具（Utilities）」**；
3. 把下载好的 `douyu-clean-v13.24.user.js` 文件**直接拖入**页面中间的虚线框；
4. 弹出安装页后点 **「安装」**。

### 第 3 步：验证是否成功

1. 打开任意斗鱼直播间，例如 [https://www.douyu.com/39939](https://www.douyu.com/39939)；
2. 页面右上角出现旋转的 **⚙ 齿轮按钮** 即安装成功；
3. 点 ⚙ 打开设置面板，可开关各项功能；
4. 直播画面应已无广告、无导航横幅，深色背景，数据面板显示真实人数。

> 💡 首次打开直播间时，Tampermonkey 可能弹出一个「用户脚本试图访问跨源资源」的对话框（脚本需要访问 `www.doseeing.com` 拉取真实数据、访问 GreasyFork 检查更新）。选择 **「总是允许」** 或 **「允许」** 即可，不影响使用。

## 🔄 更新方法

- **自动更新**：Tampermonkey 默认每 24 小时自动检查一次更新（脚本已配置 GreasyFork 更新地址）。
- **手动检查**：进入直播间 → 点 ⚙ 齿轮 → 点「检查更新」，有新版本会提示安装。
- **手动安装最新版**：重新按上面的安装方法安装本仓库最新版文件即可（新版本会覆盖旧版本，设置保留）。

## 🛠 使用方法

- 点右上角 **⚙ 齿轮按钮**（可拖动）打开设置面板，按需开关：去广告、深色背景、自动全屏、抢红包、抢宝箱、布局兜底、视口锁定。
- **去广告没清干净**：⚙ 面板 → 自定义规则 → 点 **「🎯 拾取元素」** → 直接点漏掉的广告 → 自动生成规则并立即隐藏。
- **自定义规则**：也支持手写 CSS 选择器，每行一条，点「应用规则」立即生效；误伤时删掉对应行再点「应用」即可恢复。
- **查看真实数据**：弹幕栏顶部信息条显示今日活跃 / 弹幕人数 / 礼物价值 / 贵宾 / 粉丝，鼠标悬浮显示完整说明，旁边有手动刷新按钮。

## ❓ 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 安装后提示「脚本试图访问跨源资源」 | 这是正常现象（脚本要访问数据接口），选择「总是允许」即可 |
| 数据面板显示 `--` | 等 1~2 分钟自动重试；或点信息条上的手动刷新按钮；仍不行刷新页面 |
| 小主播/新直播间数据出不来 | 主播名解析失败时按提示点击「刷新」，或等下一次自动重试 |
| 直播画面被顶出视口、要滚动才能看到 | 布局兜底默认开启会自动回收；仍不行可在 ⚙ 面板开启「视口锁定模式」 |
| 误隐藏了正常功能 | ⚙ 面板 → 自定义规则 → 删除对应行 → 点「应用规则」 |
| 签到按钮灰色不可用 | 斗鱼官方已下线直播间签到功能，无法使用 |
| 抢红包/抢宝箱没反应 | 需要登录斗鱼账号，且「自动抢礼物红包」默认关闭，需在 ⚙ 面板手动开启 |
